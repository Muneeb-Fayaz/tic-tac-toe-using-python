## 🎮 About the project

This is a small Tic-Tac-Toe web game made as a beginner-friendly Python project. The interface has a dark gradient background, glowing accent colours, a responsive board, and simple controls.

The goal was to keep the code readable and easy to learn from instead of adding complicated features that are not needed for a first project.

## ✨ Features

- Two-player gameplay on one device
- Detects wins and draws
- Highlights the winning row
- New round button
- Simple, responsive design for desktop and mobile
- Flask route for the Python backend
- Beginner-friendly file structure

## 🚀 Run it on your computer

### 1. Install Python

Install Python 3 from [python.org](https://www.python.org/downloads/). During Windows installation, tick **Add Python to PATH** if that option appears.

### 2. Open the project folder

Open a terminal in the `tic-tac-toe-python` folder.

### 3. Create a virtual environment (recommended)

**Windows:**

```bash
py -m venv venv
venv\Scripts\activate
```

**macOS / Linux:**

```bash
python3 -m venv venv
source venv/bin/activate
```

### 4. Install Flask

```bash
python -m pip install -r requirements.txt
```

### 5. Start the app

```bash
python app.py
```

Open this address in your browser:

**http://127.0.0.1:5000**

To stop the server, go back to the terminal and press `Ctrl + C`.
